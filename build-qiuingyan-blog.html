搭建 QiuLingYan 博客站全流程指南

在当今数字化时代，拥有一个个人博客是展示自我、分享知识的绝佳方式。QiuLingYan 博客站是一个现代化、高性能的静态博客系统，采用 Python 构建，专为 GitHub Pages 优化设计。本文将详细介绍如何从零开始搭建这个博客站。

准备工作

环境要求

  • Python：版本 3.7 或更高。你可以从 Python 官网 下载并安装。
  • Git：用于代码版本控制和部署。可从 Git 官网 下载安装。

获取项目代码

首先，你需要将项目代码克隆到本地。打开终端或命令提示符，运行以下命令（将 yourusername 替换为你的 GitHub 用户名）：

# 将 yourusername 替换为你的GitHub用户名
git clone https://github.com/yourusername/QiuLingYan-blog.git
cd QiuLingYan-blog

安装依赖

确保你已经安装了 Python 3.7 或更高版本，然后运行以下命令安装项目所需的依赖：

pip install -r requirements.txt

自定义博客配置

编辑 config.json 文件来自定义你的博客信息，包括博客标题、描述、作者等：

{
  "site": {
    "title": "你的博客标题",
    "description": "博客描述",
    "url": "https://yourusername.github.io",
    "author": "作者名"
  },
  "social": {
    "github": "https://github.com/yourusername",
    "twitter": "https://twitter.com/yourusername"
  },
  "features": {
    "enable_search": true,
    "enable_rss": true,
    "enable_comments": false
  }
}

添加文章

在 posts/ 目录下创建 Markdown 文件来添加你的文章。文件开头需要包含 YAML 格式的元数据，示例如下：

---
title: "文章标题"
date: 2024-08-18
tags: ["标签1", "标签2"]
description: "文章描述"
author: "作者名"
slug: "文章URL别名"
---

# 文章内容

这里是文章内容...

构建博客

完成文章添加和配置后，你可以使用以下命令构建博客：

# 构建所有文章
python blog_generator.py

# 开发模式（监听文件变化）
python blog_generator.py --watch

# 指定输出目录
python blog_generator.py --output ./my-blog

本地预览

构建完成后，你可以在本地预览博客效果。进入生成的静态文件目录，启动一个简单的 HTTP 服务器：

cd output/20250818pages  # 根据实际输出目录调整
python -m http.server 8000

然后在浏览器中访问 http://localhost:8000 查看博客。

部署到 GitHub Pages

方法1：GitHub Actions 自动部署（推荐）

  1. Fork 本仓库 到你的 GitHub 账户。
  2. 重命名仓库 为 yourusername.github.io。
  3. 启用 GitHub Pages：
  4. 进入仓库 Settings → Pages。
  5. 选择 Deploy from a branch。
  6. 选择 gh-pages 分支。
  7. 推送代码： ```bash git add . git commit -m "Initial commit" git push origin main
5. **等待部署**：几分钟后访问 `https://yourusername.github.io` 查看你的博客。

### 方法2：手动部署

```bash
# 构建静态文件
python blog_generator.py

# 初始化git仓库
cd output/20250818pages  # 根据实际输出目录调整
git init
git add .
git commit -m "Initial commit"

# 推送到GitHub Pages
git remote add origin https://github.com/yourusername/yourusername.github.io.git
git push -u origin main

总结

通过以上步骤，你已经成功搭建了一个属于自己的 QiuLingYan 博客站。接下来，你可以根据自己的需求继续添加文章、自定义主题和功能。希望这篇指南能帮助你快速上手，享受分享的乐趣！

常见问题解答

如何修改博客主题颜色？

编辑 static/css/style.css 中的 CSS 变量即可修改主题颜色。

如何启用评论系统？

在 config.json 中配置评论系统相关信息。

如何添加网站分析？

支持 Google Analytics 和百度统计，在 config.json 中添加对应的 ID 即可。
