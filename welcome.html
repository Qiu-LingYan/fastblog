📖 示例代码

让我们看一个Python函数的示例：

def fibonacci(n):
    """
    生成斐波那契数列

    Args:
        n: 要生成的项数

    Returns:
        list: 斐波那契数列
    """
    if n <= 0:
        return []
    elif n == 1:
        return [0]
    elif n == 2:
        return [0, 1]

    fib = [0, 1]
    for i in range(2, n):
        fib.append(fib[i-1] + fib[i-2])

    return fib

# 使用示例
sequence = fibonacci(10)
print(f"前10个斐波那契数: {sequence}")

📝 写作指南

文章元数据

每篇文章开头需要包含YAML格式的元数据：

---
title: "文章标题"
date: 2024-08-18
tags: ["标签1", "标签2"]
description: "文章描述"
author: "作者名"
slug: "文章URL别名"
---

支持的Markdown语法

  • 标题：# 到 ######
  • 列表：有序列表和无序列表
  • 代码块：支持语法高亮
  • 表格：Markdown表格
  • 链接和图片：支持相对路径
  • 引用：> 引用文本

🌟 开始使用

  1. 克隆仓库 bash git clone https://github.com/yourusername/ai-express-blog.git cd ai-express-blog

  2. 安装依赖 bash pip install -r requirements.txt

  5. 本地预览 打开生成的 output/ 目录中的 index.html
